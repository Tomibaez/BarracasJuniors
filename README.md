# Barracas Juniors — Sitio Web

Sitio web informativo del club Barracas Juniors, con la historia del club y enlaces directos a sus redes sociales.

🔗 **Demo en vivo:** [barrcas-juniors.vercel.app](https://barrcas-juniors.vercel.app)

## Descripción

El sitio presenta la historia e identidad del club, brindando a los visitantes información institucional junto con accesos rápidos a Facebook, Instagram y WhatsApp para mantenerse conectados con las novedades.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Características

- Diseño responsive
- Sección con la historia del club
- Enlaces directos a redes sociales (Facebook, Instagram, WhatsApp)
- Deploy en Vercel

## Cómo verlo localmente

1. Cloná el repositorio
2. Abrí `index.html` en tu navegador
